# 타석 시뮬레이션 수식 v0.1

## 0. 스케일 규약
- 표시 능력치: **20~80** (스카우팅 스케일). `z = (rating - 50) / 10`, 즉 1z = 10점 = 1 표준편차.
- 내부 저장은 0~1000 정수(성장 미세변화용). 표시 변환: `rating = 20 + internal * 60 / 1000`.
- 모든 확률은 **로그오즈(logit) 가산 모델**로 합성한다.

```
logit(p) = logit(리그기준선) + Σ (계수_i × z_i) + 상황보정
p = 1 / (1 + e^-logit)
```

이 방식의 이점: ① 확률이 0~1을 절대 벗어나지 않음 ② 능력 효과가 극단에서 자동 포화됨
③ 계수 표 하나가 게임 밸런스 시트가 됨 ④ 시대별 리그 환경을 기준선만 바꿔서 재현 가능.

## 1. 타석 결정 트리
```
1. 삼진 판정      → K
2. 볼넷 판정      → BB
3. 사구 (고정)    → HBP
4. 타구 유형      → GB / LD / FB / PU
5. 홈런 판정      → HR        (FB, LD만)
6. BABIP 판정     → OUT       (수비 성공)
7. 안타 종류      → 1B / 2B / 3B
```
각 단계가 독립 튜닝 가능해야 한다. 한 번의 난수 추첨으로 결과를 뽑는 방식은 금지.

## 3. 계수 표 (1 표준편차당 로그오즈 이동)
```
삼진   구위 +0.225 | 제구 +0.05 | 컨택 -0.150 | 삼진회피 -0.150
볼넷   선구안 +0.275 | 제구 -0.205 | 파워 +0.06
홈런   파워 +0.360 | 무브먼트 -0.185 | (구장 보정 가산)
타구   타자GB성향 ±0.30 | 투수GB성향 ±0.34 | 컨택→LD +0.08   (지수 가중치)
BABIP  주력(GB) +0.145 | 갭파워(LD/FB) +0.05 | 내야수비 -0.072 | 외야수비 -0.078 | 무브먼트 -0.06
상황   동일손 K +0.10 / BB -0.06 / HR -0.12 | 피로: 구위 -0.90×f, 제구 -0.70×f | 타순회전 +0.045/회
```
> 수비 계수가 작아 보이는 것은 의도된 것이다. 실제 MLB 최고/최악 수비팀의 팀 BABIP 차이는
> 약 .270 vs .320 뿐이다. **최종 엔진에서는 팀 합산이 아니라 타구 방향으로 담당 야수를 뽑아
> 그 선수의 수비 z를 넣어야** 스타 유격수 한 명의 가치가 제대로 반영된다.
