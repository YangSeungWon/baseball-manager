# 세이브 — 자동저장 단일 슬롯 v0.1

```
save.py   dump(game) -> dict / load(dict) -> Game
```

## 설계 결정: 불러오기를 만들지 않는다

이 장르에서 세이브 스커밍은 게임을 파괴한다. 드래프트 1순위가 망하면 되돌리고,
FA를 놓치면 되돌릴 수 있다면 — **지금까지 공들여 만든 스카우팅 불확실성이
통째로 무의미해진다.** 확신도 5%짜리 고졸을 뽑고 결과를 본 뒤 마음에 안 들면
다시 뽑으면 그만이기 때문이다.

자동저장 단일 슬롯이면 모든 결정에 무게가 생긴다. 그게 이 게임이 팔려는 감정이다.

### 단, 파일 내보내기/가져오기는 남긴다
브라우저 저장소는 날아간다 — 시크릿 모드, 사이트 데이터 삭제, 기기 변경.
20시즌 쌓은 세이브가 증발하면 치명적이다. 내보내기는 **백업이지 되돌리기가 아니다.**
항상 "현재 상태"만 내보내지므로 과거 시점으로 돌아갈 수 없다.

## 직렬화 원칙

### 1. 객체 그래프를 pid 테이블로 평탄화
선수 객체는 팀 로스터·팜·커리어·계약에서 동시에 참조된다.
`players: {pid: {...}}` 하나로 눕히고 나머지는 pid 배열만 갖는다.

### 2. 은퇴 선수는 능력치를 버리고 기록만 남긴다
통산 홈런 순위와 명예의전당에 필요한 건 **기록이지 능력치가 아니다.**
리그를 떠난 선수는 `ghosts`(이름·포지션·데뷔년도)로 축소한다.
40시즌 기준 현역 332명 / 유령 1,000명 이상 — 이 압축이 크게 작용한다.

### 3. 스카우팅 기억은 현역 것만 남긴다
각 팀은 본 적 있는 모든 선수의 능력별 오차 시드를 들고 있다.
8팀 × 1,319명 × 22개 = **23만 개**로, 압축 전에는 세이브의 최대 지분이었다.
은퇴한 선수의 오차 시드는 쓸 데가 없으므로 버린다.

### 4. RNG 상태를 함께 저장한다
리그 RNG와 시즌 RNG의 `getstate()`를 저장한다. 이어서 하는 시뮬레이션이
재현 가능해야 하고, 이게 없으면 불러올 때마다 난수열이 새로 시작된다.

### 5. 진행 중인 시즌과 드래프트도 저장한다
자동저장이라면 플레이어는 시즌 한복판에서 창을 닫는다.
그 상태가 저장되지 않으면 자동저장이라 부를 수 없다.
- 시즌: 일정·순위·선수별 누적 기록·경기 결과·불펜 등판 간격·경기일
- 드래프트: 후보 풀·남은 후보·지명 순서·이미 이뤄진 지명

## 측정 결과

| | JSON | gzip | 저장 | 복원 |
|---|---|---|---|---|
| 1시즌 + 40일 | 496 KB | **117 KB** | 12ms | 13ms |
| 15시즌 + 40일 | 976 KB | **239 KB** | 25ms | 41ms |
| 40시즌 + 40일 | 1,415 KB | **365 KB** | 38ms | 77ms |

시즌당 약 +12KB(압축 후 +6KB). 100시즌이어도 gzip 600KB 수준이다.

- `localStorage` 한도(보통 5~10MB)에 여유 있게 들어간다.
- 저장 38ms는 자동저장에 충분하다. 다만 매일 저장하면 시즌당 84 × 38ms = 3.2초가
  쌓이므로, **경기 5일마다 + 모든 단계 전환 시점**에 저장하는 것이 적당하다.
- 용량이 더 필요해지면(리그 확장, 더 긴 역사) IndexedDB 로 옮기면 된다.

## 왕복 검증
```
40시즌 진행 → 시즌 47일차에 저장 → 복원
  순위 일치 ✓   타율 1위 일치 ✓   연봉총액 일치 ✓
  스카우팅 추정 구간 일치 ✓  (57~59 → 57~59)
  이어서 시즌 완주 ✓ → 포스트시즌 → 오프시즌 ✓

드래프트 2순위 시점에 저장 → 복원
  남은 후보 30명 ✓  이미 이뤄진 지명 1건 ✓  이어서 지명 ✓
```

## 저장 중 발견한 API 버그
시즌 47일차에 리더보드가 비어 있었다. 규정타석을 시즌 전체(3.1 × 84 = 260타석)
기준으로 계산해서 시즌 중에는 아무도 충족하지 못했다. 실제 야구처럼
**치른 경기 수에 비례**하도록 고쳤다 (`3.1 × games_played`).
시즌 극초반이라 그마저 없으면 타석 상위 20명으로 대체한다.

## 남은 것
- 세이브 버전 마이그레이션이 없다. `VERSION` 불일치 시 거부만 한다.
  밸런스 패치로 계수가 바뀌면 기존 세이브를 어떻게 할지 정책이 필요하다.
- 압축을 파이썬 gzip 으로 쟀다. 브라우저에서는 `CompressionStream('gzip')` 을 쓴다.
- 포스트시즌 진행 중 저장은 아직 안 된다 (시리즈가 한 번에 끝나므로 실질 문제는 없다).
