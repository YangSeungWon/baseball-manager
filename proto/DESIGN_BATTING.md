# 타자 편 밸런스 시트 v0.1

2.5초 단판(세 스테이지)과 9이닝 경기의 공격 이닝이 공유하는 규칙 모델이다.
계수는 전부 `web/js/batting-tuning.js` 한 곳에 있고, 코드는 거기서만 읽는다.
측정은 `node tools/measure-batting.mjs [스테이지 시도] [9이닝 경기]`, 안전망은 `node --test tools/check-batting-ladder.mjs`.

## 0. 규약
- 컨택(배트에 맞을 확률, 파울 포함)은 **로그오즈 가산 모델**이다. `DESIGN_PA.md` 와 같은 규약.
  ```
  logit(컨택) = 기준선 + 능력 + 준비 층 + 실행 층
  ```
  확률 가산과 달리 극단에서 자동 포화되고, 층별 기여를 같은 단위로 비교할 수 있다.
- 타구 질(quality, 0~1)과 파울 확률은 확률·배율 가산 그대로 둔다. 타구 판정은 `field-sim.js` 의 물리 시뮬레이션이 맡는다.
- 상대 투구 생성은 플레이어의 사전 선택을 읽지 않는다. 같은 시드·같은 선택은 같은 결과를 재현한다.

## 1. 결정 트리 (한 구)
```
1. 상대 투구 생성   구종 · 존 안/밖 · 코스 · 구속      (롤 0,1,6,7)
2. 지켜보기         존 안 → S, 존 밖 → B
3. 스윙             roll[2] > 컨택 → 헛스윙 W
4.                  roll[3] < 파울확률 → F
5.                  타구 → field-sim (품질 → 속도·발사각·방향 → 수비·주루)
```

## 2. 층 구조와 설계 원칙

**실행은 준비를 구할 수 있지만, 준비는 실행을 대신할 수 없다.**

| 층 | 플레이어가 하는 일 | 항목 | 로그오즈 |
|---|---|---|---|
| 기준선 | — | 평균 타자(컨택 .72), 존 안, 자동 스윙 | logit(.78) = +1.27 |
| 능력 | — | 컨택 .05 당 | ±.30 |
| 준비 | 투구 전 구종 선택 | 적중 / 실패 | +.40 / −.35 |
| 준비 | 투구 전 코스 선택 (조준이 없을 때만) | 적중 / 실패 | +.45 / −.45 |
| 실행 | 조준 (당긴 채 드래그) | 배트와 공의 거리 d, 근접도 c = 1 − d/1.4 | −2.6 + 3.5·c (정확 +.9, 한 존 반 밖 −2.6) |
| 준비 | 장타 스윙 | | −.80 |
| 실행 | 존 밖 공에 스윙(chase) | | **−1.60** |
| 실행 | 타이밍 | 적중 / 자동 / 최대 빠름 / 최대 늦음 | **+.95** / −.20 / −.90 / −1.00 |
| 실행 | 타이밍 이탈 ≥ .6 | 배트가 공을 지나침 | 헛스윙 확정 (주사위 없음) |
| 실행 | 힘 (누른 길이, 0~1) | 장타 벌점 × 힘 | −.80 × 힘 |

검산: 타이밍 적중(+.95) > 구종·코스 실패(−.35, −.45). 틀리게 찍고 잘 친 사람은 여전히 플러스다.
존 밖 스윙(−1.60)은 어떤 준비로도 만회되지 않는다. 그 순간의 읽기가 가장 큰 단일 항목이다.
준비 층의 숨은 가산은 일부러 작다. 예측 성공의 진짜 보상은 아래 **읽기 창 보상**이다.

### 예측 성공 = 정보 (`read.reward`, 창 비율)
| 적중 | 효과 |
|---|---|
| 구종 | 창 시작 −.06, 선명도 시작 −.10, 타이밍 적중 구간 시작 −.05 |
| 코스 | 창 시작 −.04, 창 끝 +.04, 타이밍 적중 구간 끝 +.05 |
| 실패 | 창은 그대로(벌점 없음). 컨택 로그오즈만 위 표만큼 내려간다. |

투구와 지켜보기 판정은 예측과 무관하다. 하네스는 창을 재지 못하므로(정책은 항상 적중 구간 중앙에서 스윙) 이 보상은 실제 플레이에서만 나타난다.

### 타구 질 (컨택 이후)
| 항목 | 값 |
|---|---|
| 타자 편 기준 오프셋 `bip.bonus.base` | −.12 (투수 편과 분리된 타자 편 전용) |
| 타이밍 적중 / 최대 빠름 / 최대 늦음 | +.08 / −.18 / −.22 |
| 구종 적중 / 코스 적중(×½) / 존 밖 | +.05 / ±.03 / −.12 |
| 조준 | 타구 질 가산 ±.10·(2c−1), 배율 .70 → 1 (c), 안팎 오차 × 14° 스프레이 |
| 배율: 컨택 스윙 / 코스 실패 / 구종 실패 / 존 밖 | .92 / .78 / .90 / .72 |
| 타이밍 방향 | 빠름 최대 −28° (당김) / 늦음 최대 +24° (밀림) |
| 파울 | 컨택 .32 → 장타 .20 (힘으로 보간) · 적중 −.05 · 빗나감 최대 +.16 |
| 힘 입력 | 누른 길이 110 ms 까지 컨택(0), 420 ms 부터 장타(1), 사이 선형 |

### 상대 투구 생성
| 항목 | 값 |
|---|---|
| 구종 | roll[0] < fast → 직구, 나머지의 58% 슬라이더, 42% 체인지업 |
| 존 안 | .64 · 3볼 +.17 · 2스트라이크 −.20 · [.20, .88] |
| 코스 | 존 안 x ±.6, 존 밖 ±1.6 · z 3분할 (−.7 / 0 / .65), 존 밖 −1.5 |

### 읽기 창 (화면)
`from = .34 − .17·시력`, `to = .48 + .24·시력`, `takeUntil = .48 + .42·선구안`, 선명도 시작 `.43 − .26·시력`, 창 2500 ms.
타이밍 적중 구간 `.55 ~ .85`.

### 9이닝 상대 투수의 문법 (`pitcher-grammar.js`, `grammar` 그룹)
| 항목 | 값 |
|---|---|
| 투수당 선택 규칙 / 단서 | 4 / 1 · 시드 기반 지역 LCG로 선택 (`game.rng` 와 무관) |
| 규칙 발동 | 조건 충족 시 `roll[8] < consistency` (.75 ~ .90). 첫 매칭 규칙만 발동. 미발동이면 시드의 원래 투구 |
| 결정구 | 투수마다 슬라이더 또는 체인지업 하나. "변화구" 규칙은 이 결정구로 수렴 |
| 단서 | 미트 위치 .80 / 템포 .75 신뢰. `roll[9]` 로 진실 여부 결정. 투구는 바뀌지 않음 |
| 불펜 | 7회 말부터 두 번째 투수(다른 문법) |
| 조정 | 한 규칙에서 안타 2회 → 그 규칙만 예비 규칙과 교체, 화면에 알림 |

규칙 풀: 초구 직구 · 2스트라이크 바깥쪽 결정구 · 3볼 직구 존 안 · 1-1 직구 존 안 · 몸쪽 직구 다음 바깥쪽 변화구 ·
같은 구종 3연속 금지 · 득점권 변화구 · 유리한 카운트 유인구 · 7회 이후 직구 −4 km/h(항상) · 미트 단서 · 템포 단서.

## 3. 목표 사다리

정책은 `tools/measure-batting.mjs` 에 있다. 각 정책은 앞 정책에 한 가지 기술을 더한다.

| 정책 | 뜻 | 스테이지 1 클리어 목표 |
|---|---|---|
| 무작위 | 스윙/참기 반반, 타이밍 없음 | 8 ~ 14 % |
| 존 판독 | 존 안만 스윙, 자동 타이밍 | 20 ~ 30 % |
| + 타이밍 | 적중 구간에서 스윙 | 38 ~ 48 % |
| + 예측 적중 | 다음 공을 미리 알고 구종·코스 선택 | 50 ~ 60 % |

의도: 실패가 기본이되 배울수록 확실히 오른다. 실행 두 단계(존 판독 + 타이밍)의 상승폭이 준비(예측)의 상승폭보다 크다.
9이닝 학습 정책(카운트별 기억 vs 기억 없음)의 목표: 확신 있을 때만 노리는 학습자(4구 이상 관찰, 70% 이상 쏠림)가
예측 시도 10~25%, 정확도 55% 이상(기저율 37%), 득점은 손해 없음. 하네스는 읽기 창 보상을 재지 못하므로 득점 차는 과소평가다.

## 5. 알려진 한계 · 다음 단계
- **9이닝 득점이 많다.** 존 판독 + 타이밍 정책이 말 공격만으로 경기당 14~15점을 낸다. 단판 스테이지의 클리어율에 맞춘 값이 9이닝에서는 너무 후하다. 9이닝 전용 난이도 축(투수 문법의 존 밖 비율, `bip.bonus.base` 의 9이닝 오프셋)이 필요하다. 상대 초 공격은 하네스에서 고정 정책으로 던지므로 승률 수치는 참고만 한다.
- 스테이지 2(동점 1사 3루, 1점이면 끝)는 어떤 정책에도 쉽다. 스테이지별 난이도 축(수비 송구력, 주자 주력)을 목표 사다리에 넣어야 한다.
- 학습자 하네스는 카운트만 기억한다. 순서 규칙·단서를 쓰는 학습자를 추가하면 문법의 학습 가능성을 더 정확히 잰다.
- 무작위 정책은 "반반 스윙"이라 실제 초보보다 나쁘다. 초보 목표 8~14%는 그 점을 감안한 값이다.
- 타구 물리와 수비는 투수 편과 공유한다. 타자 편만 조정하려면 `bip.bonus.base` 를 쓴다.

## 7. 투수 편 (한 이닝 승부 · 투수) 측정

`node tools/measure-pitching.mjs [시도]`, 안전망 `node --test tools/check-pitching-ladder.mjs`.
정책은 코스·구종을 평범하게 섞고(2S 전에는 존 승부, 2S면 유인구) 힘 선택만 다르다. 릴리스는 정확한 순간을 노리되
손 떨림 σ(초보 .12, 숙련 .05)만큼 빗나간 진행도에서 게이지를 읽는다. 화면과 같은 수식이라 "보이는 오차가 곧 실제 오차"다.

| 항목 | 값 |
|---|---|
| 게이지 → 위치 | 오차 1 = 존 한 칸. 빠르면 높고 몸쪽, 늦으면 낮고 바깥 (x 1.0, z 1.2) |
| 힘 | 숨 고르기: 바늘 .85배·흔들림 ¼·구속 −1·컨택 +.02·피로 .6 / 전력: 바늘 1.45배·흔들림 1.6배·구속 +4·컨택 −.055·피로 2.2 |
| 피로 | 투구 수 대신 실린 힘의 누적. 15 를 넘으면 구당 .009 씩 제구가 흔들림 |
| 존 밖 추격 | 한 칸 밖이면 거의 참는다: chase × clamp(1 − 밖으로 나간 거리, .08, 1) |
| 실투 | 존 안에서 가운데로 몰린 정도(meat 0~1) × 컨택 +.12, 타구 질 +.22 |

원칙: **전력 남발은 손해, 숨 고르기는 초보에게 이득, 2스트라이크 전력은 손해가 아니다.** 아래 결과가 그 순서를 보여준다.

| 손 | 정책 | 성공률 % | 볼넷/구 % | 피안타/구 % |
|---|---|---|---|---|
| 초보 | 항상 보통 | 38.1 | 1.7 | 15.2 |
| 초보 | 항상 전력 | 38.8 | 1.9 | 13.8 |
| 초보 | 2스트라이크만 전력 | 38.1 | 1.6 | 15.7 |
| 초보 | 주자 득점권·3볼이면 숨 고르기, 2S 전력 | 38.7 | 1.2 | 16.7 |
| 초보 | 항상 숨 고르기 | 39.2 | 1.0 | 16.2 |
| 숙련 | 항상 보통 | 42.7 | 0.6 | 15.9 |
| 숙련 | 항상 전력 | 41.8 | 1.1 | 14.4 |
| 숙련 | 2스트라이크만 전력 | 42.2 | 0.9 | 15.9 |
| 숙련 | 주자 득점권·3볼이면 숨 고르기, 2S 전력 | 42.3 | 0.9 | 16.8 |
| 숙련 | 항상 숨 고르기 | 42.1 | 0.2 | 16.9 |

(1500회) 전력 남발은 숙련자에게 손해이고 초보에게는 잡음 범위 안에서 같다. 얻는 것(헛스윙·피안타 감소)과 잃는 것(제구·볼넷·실투)이 맞물려 지배 전략이 아니다. 숨 고르기는 볼넷을 절반으로 줄이고, 손이 안정될수록(σ .12→.05) 성공률이 4~5 포인트 오른다.
