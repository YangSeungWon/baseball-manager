# 드래프트 / 스카우팅 v0.1

```
scouting.py   스카우트 조직, 오차 모델, 리포트
draft.py      아마추어 선수 풀 생성, 스카우팅 예산 배분, 지명 실행
career.py     (개편) 신인 균등 배분 → 드래프트, 팜 판단을 스카우팅 추정치로
show_draft.py 드래프트 보드 vs 실제 결과
validate_draft.py 지명 순위별 성과 검증
```

## 스카우팅 — 목적은 "틀린 정보를 주는 것"

### 원칙 1. 팀은 진실이 아니라 자기 추정치로 판단한다
`career.py`의 팜 승격 / 방출 / 로스터 경쟁 판단이 전부 `dev.overall()`(진실)에서
`self.see(t, p).ovr`(그 팀의 추정)로 바뀌었다. 팀은 자기가 과대평가한 유망주를
승격시키고, 과소평가한 선수를 방출한다.

### 원칙 2. 오차는 (팀, 선수) 쌍마다 고정된다
같은 선수를 다시 봐도 추정이 흔들리지 않는다. 관찰을 늘리면 오차의 **크기만**
줄고 방향은 유지된다. 한 팀이 특정 선수를 계속 과대평가하는 일이 자연히 생긴다.

### 원칙 3. 오차의 72%는 리그 전체가 공유한다
이게 이 모듈에서 가장 중요한 발견이다.

팀마다 **독립적으로만** 틀리면 드래프트 순위가 개별 스카우트보다 훨씬 정확해진다.
8팀의 오차가 서로 상쇄되기 때문이다. 실제로 측정했더니:

```
개별 팀의 평가 ↔ 통산 WAR   0.270      ← 현실적
지명 순위     ↔ 통산 WAR   0.435      ← 훨씬 정확하다
```

실제 드래프트에서는 모든 구단이 비슷한 정보를 보고 **같은 방향으로** 틀린다.
그래서 전체 1순위가 통째로 망하는 일이 벌어진다. 오차를
`공유 오차 × √0.72 + 팀 고유 오차 × √0.28` 로 분해했다.

### 오차 크기
| | 현재 능력 | 잠재력 |
|---|---|---|
| 아마추어 | 6.5 | **16.0** |
| 프로(1군 기록 보유) | 2.2 | 7.0 |

여기에 곱해지는 것들:
```
스카우트 능력   0.45 ~ 1.30배   (부서의 eval_current / eval_potential / 타격·투수 지식)
관찰량         1 / √(1 + 0.40 × 관찰횟수)
선수 난이도     고졸 1.20 / 대졸 0.62
구단 편향       툴별 고정 편향 (이 팀은 주력을 과대평가한다 같은)
```
**잠재력 오차가 현재 능력 오차의 2.5배**다. 이게 드래프트의 재미다.

### 숨은 성향은 숫자로 노출하지 않는다
```
성실성 65+ → "훈련 태도가 대단히 성실하다."
성실성 38- → "훈련 태도에 관한 우려가 있다."
부상성향 63+ → "부상 이력과 체질이 걱정스럽다."
관찰 1회 이하 → "관찰 기회가 적어 평가의 불확실성이 크다."
```

## 드래프트

```
매년 아마추어 60명 생성
   고졸 60% (18세)  — 예측이 어렵다(난이도 1.20). 상한도 하한도 넓다.
   대졸 40% (21세)  — 3년치 성장을 이미 썼고 잠재력 +1.4 보정.
                      예측이 쉽다(0.62). 하한이 높고 상한이 낮다.
        ↓
스카우팅 예산 배분 — 전원 1회씩 훑은 뒤, 자기 보드 상위에 자원을 더 쓴다
   상위 12명 +3회 / 13~26위 +2회 / 27~42위 +1회
   ※ 스카우트가 나쁜 팀은 '어디에 자원을 쓸지'부터 틀린다
        ↓
4라운드 × 8팀 = 32명 지명 (성적 역순)
   지명 가치 = 상향가중 × 추정잠재력 + (1-상향가중) × 추정현재능력
               + 포지션 프리미엄(C +2.2 / SS +1.8 / 1B -1.6 / DH -2.6)
   상향가중은 구단마다 0.55~0.85 — 유망주를 좋아하는 팀과 즉시전력을 좋아하는 팀
        ↓
지명자는 팜으로. 미지명 28명은 사라진다.
팜 정원 18명 — 초과 시 '자기 팀 평가' 하위부터 방출
```

## 검증 (50시즌, 분석 대상 1120명)

| 구간 | 인원 | 1군진입 | 평균 WAR | 스타(20+) | 성공(5+) | 실패(<3) |
|---|---|---|---|---|---|---|
| 1라운드 | 280 | 92% | 12.4 | 22% | 68% | 18% |
| 2라운드 | 280 | 71% | 4.5 | 5% | 30% | 34% |
| 3라운드 | 280 | 51% | 2.3 | 2% | 15% | 30% |
| 4라운드 | 280 | 41% | 0.9 | 0% | 6% | 30% |
| **전체 1순위** | 30 | 97% | 18.4 | 40% | 83% | **13%** |

전체 1순위도 13%는 통산 WAR 3 미만으로 끝난다.

### 스카우팅 오차의 효과 — 대조군 실험
스카우팅 오차를 0으로 놓은 **완벽한 정보** 리그를 따로 돌려 비교했다.

| | 1R | 2R | 3R | 4R | 순위↔WAR 상관 |
|---|---|---|---|---|---|
| 완벽한 스카우팅 | 13.1 (92%) | 3.8 (60%) | 1.1 (35%) | 0.5 (15%) | **0.552** |
| 실제 스카우팅 | 12.4 (92%) | 4.5 (71%) | 2.3 (51%) | 0.9 (41%) | **0.477** |

스카우팅 오차가 **3라운드의 가치를 2배로, 4라운드 진입률을 15%→41%로** 끌어올린다.
"하위 라운드에서 터진다"가 수치로 확인된다. 1라운드는 거의 변하지 않는다 —
최상위 재능은 틀리기 어렵다.

### 실제 드래프트 보드 (2034년 학년, 29년 뒤 시점)
```
순위 지명팀        선수   출신   P    지명당시 평가  확신 │ 실제 결과
1   수원 바이슨    송민열  대졸  LF      67~73   66% │ ○ 20시즌 WAR 19.5
3   청주 포세이돈  류동기  고졸  SP      61~79    5% │ ×      1군 진입 실패
4   광주 드래곤스  김기열  고졸  LF      60~76   13% │ × 21시즌 WAR  -0.8
6   대구 스톰      박시수  대졸  SP      58~63   73% │ ○ 11시즌 WAR  14.5
11  청주 포세이돈  한재용  고졸  RP      60~79    5% │ ×      1군 진입 실패
15  대전 코메츠    한기준  고졸  2B      57~74    6% │ ○ 18시즌 WAR  19.9
```
대졸은 확신도 66~73%에 `58~63` 같은 좁은 구간, 고졸은 5~13%에 `60~79`.
**고졸/대졸의 위험 프로필 차이가 설계된 게 아니라 오차 모델에서 저절로 나온다.**

## 뜻밖의 부수효과 — 커리어 길이 문제가 풀렸다
지난 모듈에서 남긴 최대 한계였던 "1군 커리어가 너무 길다"가 드래프트를 넣자
크게 개선됐다.

| | 부상 모듈까지 | 드래프트 이후 |
|---|---|---|
| 평균 커리어 | 9.2시즌 | **7.7시즌** |
| 중앙값 | 9 | **7** |
| 평균 은퇴 나이 | 31.2세 | **30.2세** |
| 통산 WAR 5+ 비율 | 45% | **40%** |
| 통산 WAR 20+ 비율 | 12.1% | **8.1%** |

원인은 명확하다. 이전에는 팀이 매년 12명의 유망주를 **자동으로 받았다**.
이제는 60명 중 32명만 지명되고 팜 정원이 18명이라, 유망주끼리 자리를 놓고
경쟁한다. 한계 선수들이 파이프라인을 통과해 나가면서 회전율이 올라갔다.

## 알려진 한계
- **지명순위↔WAR 상관 0.477은 실제 MLB(0.2~0.3)보다 높다.** 대조군이 0.552이므로
  스카우팅 오차는 제 몫을 하고 있고, 나머지는 구조적이다. 8팀 리그에서 60명 풀 중
  32명만 뽑는 4라운드 드래프트는 MLB의 20라운드 1200명 드래프트보다 본질적으로
  예측력이 높다(MLB는 후반 지명자 대부분이 WAR 0이라 상관계수가 눌린다).
  라운드와 풀을 늘리면 자연히 내려간다.
- **국제 아마추어 시장이 없다.** 드래프트가 유일한 선수 유입 경로다.
- **지명 거부 / 계약금 협상이 없다.** 지명하면 무조건 입단한다.
- **트레이드로 지명권을 주고받을 수 없다.** (트레이드 모듈에서)
- 스카우트가 부서 단위로 추상화돼 있다. 개별 스카우트 고용/해고가 없다.
- 팀의 스카우팅 예산이 고정이다. 재정 모듈이 붙으면 예산 배분이 선택이 된다.
