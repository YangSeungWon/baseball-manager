# 계약 / FA / 트레이드 v0.1

```
contract.py   계약, 연봉 산정, 서비스 타임, 보유권, 구단 재정
market.py     FA 시장, 트레이드 AI, 팀 방향성
career.py     (개편) 오프시즌에 재정 갱신 → FA → 트레이드 → 로스터 정리 → 드래프트
show_offseason.py / validate_market.py
```

## 화폐 단위와 스케일 (KBO 감각)
```
최저연봉 0.30억 / 1 WAR 가격 4.2억 / 팀 예산 60~150억 / 최고 FA 연평균 25~30억
FA 자격 = 1군 등록 7시즌 / 연봉조정 자격 3시즌
```

## 서비스 타임 — 세 구간
```
0~2년차   시장가의 4~13%   (최저연봉 근처)
3~6년차   시장가의 32~80%  (연봉조정)
7년차~    FA — 시장이 값을 정한다
```
젊은 스타가 싸다. 그래서 리빌딩 팀의 자산이 되고, 트레이드에서 비싸게 팔린다.

## 구단 재정
```
market_size    0.55 ~ 1.50   (연고 규모)
owner_spending 0.60 ~ 1.40   (구단주 성향)
수입 = (62 + 58×시장규모) × 성적계수 + 포스트시즌/우승 보너스
예산 = 수입 × 0.86 × 구단주성향
```
예산을 넘기면 `_shed_salary`가 연봉 대비 가치가 낮은 선수부터 방출한다.
검증: 예산 초과 팀-시즌 1%, 연봉총액 평균 91억 / 예산 107억 (집행률 85%).

## FA 시장
```
계약 만료 → FA 자격(7시즌) 있으면 시장으로, 없으면 보류권으로 자동 갱신
        ↓
가치 높은 선수부터 순서대로 시장에 나온다
        ↓
각 팀이 오퍼: 희망액 × (0.70 + 0.58×니즈 + 0.32×예산여력) × 무작위(0.88~1.16)
   니즈 = 우리 로스터의 그 자리 선수보다 얼마나 나은가 (스카우팅 추정 기준)
   예산이 없어도 최저 계약은 언제나 가능 (뎁스 확보)
        ↓
선수가 고른다: 효용 = w_돈×금액 + w_우승×팀성적 + w_출전×주전가능성 + w_충성×원소속
   네 가중치는 전부 숨은 속성이다
```
검증: 시즌당 39.9명 계약, **이적률 60%**, 최대 계약 평균 145억.

## 트레이드

### 팀 방향성
지난 시즌 승률과 라인업 평균 나이로 결정한다.
검증 결과 우승도전 37% / 중립 37% / 리빌딩 26%.

### 가치 = 보유 기간 동안의 (생산 × 시점가중 − 연봉)
연도 오프셋별 가중치:
```
우승도전  1.45  1.18  0.92  0.72  0.58  0.48
중립      1.04  1.02  1.00  0.96  0.92  0.88
리빌딩    0.55  0.82  1.12  1.28  1.30  1.24
```
스카우팅 추정 능력치로 계산하므로 **팀마다 같은 선수를 다르게 평가한다.**
양쪽 모두 자기 눈으로 +6억 이상 이득일 때만 성사된다.
한 오프시즌에 팀당 최대 2건.

### 검증 (35시즌)
| 팀 방향 | 1군 영입 | 1군 방출 | 유망주 순유입 |
|---|---|---|---|
| 우승도전 | 131 | 15 | **−116** |
| 중립 | 49 | 88 | +39 |
| 리빌딩 | 15 | 92 | **+77** |

우승도전 팀은 유망주를 팔아 즉시전력을 사고, 리빌딩 팀은 정확히 반대로 한다.
설계한 대로다.

## 튜닝 중 잡은 버그 세 개

### 1. 원소속 팀만 예산 상한을 면제받고 있었다
제가 넣은 예외 한 줄 때문에 **원소속 팀이 71%의 확률로 최고액을 제시**했고,
FA 이적률이 8%에 묶여 있었다. 모든 팀에 같은 상한을 적용하고 원소속 팀에는
10% 여유만 주도록 고쳤다. → 이적률 8% → **60%**.

### 2. 모드 가중치가 나이가 아니라 '계약 잔여 연수'에 붙어 있었다
1년 계약자는 가치의 100%가 올해에 몰리므로, 우승도전 팀이 24세든 33세든
1년 계약자를 무조건 높게 쳤다. 결과가 완전히 거꾸로 나왔다.
```
              1군 영입 평균나이   1군 방출 평균나이
우승도전            24.3            28.6      ← 젊은 선수를 사고 늙은 선수를 팔았다
리빌딩              29.2            24.4      ← 정반대
```
원인은 **보유권을 계산에서 빼먹은 것**이었다. 계약이 끝나도 FA 자격 전이면
값싸게 계속 쓸 수 있는데, 그걸 자산으로 세지 않으니 '1년 계약 24세'가
리빌딩 팀에게 무가치해졌다. `control_horizon()`으로 계약 + 보유권 기간
전체를 계산하도록 고쳤다.

### 3. 트레이드가 우승 편중을 만들었다
48시즌에서 한 팀이 17번 우승했다(균등이면 6, 우연 기대치 ~10).
대조군으로 트레이드를 끄자 17 → 10으로 떨어졌다. 우승도전 팀이 한 오프시즌에
무제한으로 선수를 쓸어담는 것이 원인이었다. 팀당 2건으로 제한했다.

| | 최다 우승 / 48시즌 |
|---|---|
| 수정 전 | 17 / 10 / 13 |
| 수정 후 | **10 / 11 / 11** (우연 기대치 수준) |

시장 규모는 원인이 아니었다 — 시장규모↔우승 상관은 **−0.208**이었다.

## 알려진 한계
- **트레이드가 연봉 여력을 보지 않는다.** 그래서 우승도전 팀이 고연봉 베테랑을
  받아들이는 결정을 제대로 못 한다. 1군 영입 평균나이가 방향별로 거의 같은
  (±0.7세) 이유다. 유망주 ↔ 즉시전력 축은 제대로 작동하지만, 나이 축은 아직 약하다.
- 트레이드는 오프시즌에만 일어난다. 시즌 중 마감시한 트레이드가 없다.
- 1:1 교환만 가능하다. 다대다, 지명권 포함, 삼각 트레이드가 없다.
- 계약에 옵션 / 인센티브 / 트레이드 거부권 / 바이아웃이 없다.
- FA 보상선수 / 보상금이 없다 (KBO식 등급제 FA 미구현).
- 방출 선수는 미계약 신분으로 두 번의 오프시즌만 버틴다. 2군 계약이 없다.
- 구단주 인내심 / 감독 경질이 없다.
