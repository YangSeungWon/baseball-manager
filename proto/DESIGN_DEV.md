# 성장 / 노화 시스템 v0.1

```
development.py   숨은 성향, 노화 곡선, 성장/하락, 은퇴 판정
roster.py        (개편) 18세 유망주 생성 → 성장 엔진으로 나이 먹이기, 팜, 로스터 재구성
career.py        다년 루프: 시즌 → 성장/노화 → 은퇴 → 팜 승격 → 신인 유입
validate_dev.py  50~60시즌 장기 검증
show_career.py   선수 커리어 카드
```

## 원칙 1 — 능력마다 노화 곡선이 다르다
단일 "현재능력 CA / 잠재력 PA" 모델은 예측이 너무 쉽고 야구답지 않다.
능력별로 (정점나이, 성장계수, 하락계수)를 따로 준다.

| 능력 | 정점 | 성장 | 하락 | 결과 |
|---|---|---|---|---|
| speed | 23.0 | 0.70 | **1.95** | 21세 정점 → 38세까지 -14점, 가장 먼저 죽는다 |
| fielding | 25.0 | 0.75 | 1.25 | 주력을 따라 무너진다 |
| stuff | 25.0 | 1.00 | **1.30** | 구위는 일찍 정점 |
| contact | 26.0 | 1.00 | 1.00 | 기준 |
| gap_power | 27.0 | 1.00 | 0.85 | |
| movement | 27.0 | 0.90 | 0.75 | |
| hr_power | 28.0 | 1.05 | 0.75 | 늦게 정점, 오래 간다 |
| discipline | 28.5 | 0.80 | **0.50** | 거의 안 떨어진다 |
| command | 28.5 | 0.90 | **0.55** | 나이 들수록 오히려 좋아 보인다 |

이 표 하나로 *"30세에 무너지는 수비형 유격수"* 와 *"35세까지 버티는 선구안 좋은 1루수"*,
*"구속을 잃고 제구로 먹고사는 노장 투수"* 가 전부 자동으로 나온다.

## 원칙 2 — 잠재력은 고정값이 아니다
매년 `gauss(0, drift_sd)` 만큼 흔들린다 (22세 이하 2.4, 26세 이하 1.4, 그 이상 0.7).
여기에 매년 6% 확률 각성 시즌(성장률 ×2.3), 8% 확률 정체 시즌(×0.15)을 얹는다.
→ 늦게 터지는 선수와 끝내 터지지 않는 유망주가 동시에 존재한다.

## 원칙 3 — 베테랑을 난수로 찍지 않는다
초기 리그의 30세 선수는 **18세 유망주를 만든 뒤 성장 엔진을 12번 돌려서** 만든다.
그래야 리그의 나이-능력 분포가 성장 모델과 모순되지 않는다.
후보를 3명 만들어 최고를 남기면 "살아남은 30세"라는 생존 편향까지 자연히 재현된다.

부작용: 노화를 거치면 능력치 평균이 50 아래로 내려가 타석 엔진의 리그 기준선과
어긋난다. `roster.CALIB` 로 잠재력 분포를 능력별로 밀어 올려 보정했다
(주력 +6.8, 체력 +7.9, 선구 +2.8 ...). 검증 결과 11개 능력 전부 50.0 ± 0.1.

## 성장 / 하락 공식
```
성장 (나이 < 정점):
    youth = (정점 - 나이) / (정점 - 17)
    격차  = 잠재력 - 현재
    비율  = 0.165 × youth × 성장계수 × 노화유형 × 성실성 × 출전기회
            × 개인성장률 × 각성/정체 × uniform(0.6, 1.4)
    현재 += 격차 × min(비율, 0.75)

하락 (나이 ≥ 정점):
    경과 = 나이 - 정점
    폭   = 0.34 × 하락계수 × 노화유형 × 개인하락률 × (1 + 0.17×경과)
           × uniform(0.45, 1.55) × (1.25 - 0.25×프로의식/50)
    현재 -= 폭
```
`성실성`은 0.65~1.75배로 작용한다. 잠재력 80이 둘이어도 성실성 90과 35는
5년 뒤 능력 차이가 크게 벌어진다. 플레이어는 이 값을 직접 볼 수 없다(스카우팅은 후속 모듈).

## 노화 유형 (숨은 속성)
`EarlyPeak(16%) / Normal(42%) / LateBloomer(16%) / SlowDecline(14%) / RapidDecline(12%)`
각각 (정점나이 보정, 하락계수 보정, 성장계수 보정)을 가진다.

## 은퇴
나이별 기본 확률 + 대체 수준(OVR 41) 이하면 +0.30 이상, 출전 기회가 없으면 +0.12,
OVR 60 이상이면 ×0.45, 야망이 높으면 감소. 44세 강제 은퇴.

## 선수 파이프라인 (지금 구조)
```
매년 신인 생성 (18세)
      ↓
    팜(2군) - 팀당 12명, 매년 성장, 25세가 되면 승격 아니면 방출
      ↓  승격 조건: 빈 자리 채우기  또는  1군 최약체보다 OVR +0.8 이상
    1군 (타자 13 / 투수 12)
      ↓
   성장 → 정점 → 노쇠 → 방출(24세 이하면 2군 복귀) 또는 은퇴
```
포지션 공백이 생겼는데 그 자리 선수가 대체 수준(43) 아래면 유망주가
**포지션을 전향**해서 메운다.

> **드래프트는 아직 없다.** 지금은 신인이 팀에 균등 배분된다.
> 드래프트는 이 파이프라인의 맨 위, "누가 어느 팀 팜에 들어갈지 순번대로 고르는"
> 한 단계를 끼워 넣는 작업이다. 파이프라인 자체는 이미 완성돼 있다.

## 검증 — 나이별 생산성 (WAR)
타자 WAR이 **28세(1.52)에 정점**을 찍고 하락한다. 19세 0.92 → 28세 1.52 → 38세 0.83.
투수는 곡선이 평평한데, 이는 규정이닝을 채운 투수만 표본에 들어가는 선택 효과가
타자보다 훨씬 강하기 때문이다 (못 던지면 아예 이닝을 못 먹는다).

## 알려진 한계
- **1군 커리어가 너무 길다** (평균 10.4시즌, 중앙값 11). 실제 MLB는 평균 5~6년.
  원인은 명확하다: 25인 고정 로스터 + 부상 없음 + 주전 9명이 84경기를 전부 소화.
  실제 팀은 한 시즌에 45~50명을 쓴다. **부상 시스템이 들어가면 자연히 짧아진다.**
- FA / 트레이드 / 계약이 없어 방출 = 은퇴다. 다른 팀에서 뛸 기회가 없다.
- 스카우팅이 없어 잠재력·숨은 성향이 전부 정확히 보인다.
  (플레이어에게 보여줄 때 오차 범위를 씌우는 것이 다음 단계)
- 2군 경기를 실제로 시뮬레이션하지 않는다 (설계대로 추상화).
- 신인이 팀에 균등 배분된다 (드래프트 없음).
