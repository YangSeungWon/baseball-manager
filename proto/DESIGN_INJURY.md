# 부상 시스템 v0.1

```
injury.py     발생 확률 / 심각도 / 영구 손상
roster.py     (추가) set_active — 그날의 출전 명단, 부족하면 콜업
season.py     (추가) 매 경기일 회복 처리, 경기 후 부상 판정, 부상 로그
career.py     (추가) 비시즌 회복, 로스터 정원 복귀, 중상 이력 기록
```

## 2단계 구조
발생과 심각도를 분리한다. 하나로 합치면 "부상 확률"이라는 단일 손잡이밖에 안 남는다.

**1) 발생** — 출전 1회마다 굴린다.
```
확률 = 기본치 × (0.55 + 0.90×부상성향/50) × 나이계수 × (1 + 0.85×피로) × 투구량

기본치   타자 0.0063 / 선발 0.0170 / 구원 0.0078   (출전 1회당)
나이계수  25세 이하 0.80,  이후 1.0 + 0.052×(나이-27)
```
피로가 곱해지는 것이 핵심이다. 지친 선발을 계속 끌고 가면 실제로 부러진다.
`부상성향`은 숨은 속성이라 플레이어가 볼 수 없다.

**2) 심각도** — 결장 일수를 뽑는다. 투수가 더 심하게 다친다.

| 등급 | 일수 | 타자 | 투수 |
|---|---|---|---|
| 경상 | 4~15 | 56% | 48% |
| 중경상 | 16~45 | 30% | 32% |
| 중상 | 46~130 | 11% | 14% |
| 시즌아웃 | 150~330 | 3% | 6% |

## 영구 손상 — 이 시스템의 존재 이유
46일 이상 중상은 능력치와 **잠재력**에 영구 손상을 남긴다.
```
scale = min(1, (일수 - 45) / 190)
손상량 = 6.5 × scale × 능력별배율 × uniform(0.5, 1.5)
잠재력도 손상량의 75%만큼 함께 깎인다
부상성향 += 5 × scale        ← 한 번 다친 몸은 또 다친다
```
| 타자 | 배율 | | 투수 | 배율 |
|---|---|---|---|---|
| speed | 1.00 | | stuff | 1.00 |
| fielding | 0.60 | | stamina | 0.80 |
| contact | 0.28 | | movement | 0.35 |
| gap_power | 0.22 | | command | 0.30 |

주력과 구위가 가장 크게 깎인다. **팔꿈치를 다친 파이어볼러는 다시는 그 구속을
되찾지 못한다.** 이게 커리어 서사를 만드는 지점이다.

## 로스터 운영
```
매 경기일:  부상일수 -1  →  set_active()  →  불펜 등판 가능 여부
set_active: 건강한 선수만으로 라인업 9 / 로테이션 5 / 불펜 구성
            건강한 타자 <10, 투수 <9, 선발 <4 이면 팜에서 콜업
비시즌:     120일 회복, 콜업으로 불어난 로스터를 정원(타자13/투수12)으로 정리
```

## 검증
| 항목 | 결과 | 실제 야구 |
|---|---|---|
| 팀당 부상 건수 | 14.0건/84경기 → **162경기 환산 27건** | 25 ~ 30건 |
| 팀당 결장 연인원 | 477일 → 162경기 환산 921일 | ~1400일 |
| 팀당 중상(46일+) | 2.6건/시즌 | |
| 시즌당 출전 타자 | 95명 (부상 없을 때 72명) | |
| 백업 선수 타석 비중 | 팀 타석의 12% | ~25% |
| 규정타석 충족 | **60명** (부상 없을 때 72명) | 45 ~ 60 |
| 리그 타율 / RA9 | .253 / 4.45 | .250~.265 / 4.30~4.80 |

60시즌 표류: 타율 +.002, RA9 -0.13. 리그 환경은 그대로 유지된다.

## 부상이 만든 커리어 (실제 출력)
```
유민혁  SS  우타   데뷔 2035(19세) ~ 은퇴 2046(31세)   통산 WAR 39.1  MVP 2회
  2038 22세  84경기 .265/.358/.565  26HR   4.2
  2039 23세  42경기 .244/.337/.523  12HR   1.8   ⚠ 시즌아웃 (214일)
  2040 24세  33경기 .277/.374/.596  12HR   2.0
  2041 25세  84경기 .216/.313/.461  21HR   2.2
  2045 29세  84경기 .291/.377/.645  36HR   5.4 ★
  2046 30세  20경기 .309/.429/.827  12HR   2.0   ⚠ 중상 (76일)
  [부상 이력] 통산 7회 / 451일 결장
```
23세 시즌아웃 → 2년간 반쪽 시즌 → 26세부터 회복 → 29세 커리어 하이 →
30세에 또 중상 → 31세 은퇴. 템플릿 없이 시스템에서 자동으로 나온 서사다.

## 예상이 빗나간 부분 (기록해 둠)
직전 모듈에서 **"부상이 들어가면 커리어 길이가 자연히 짧아진다"고 예상했으나 틀렸다.**
부상은 커리어 길이를 거의 바꾸지 않았다 (10.4 → 11.1시즌). 실제 원인을 측정했다.

```
리그 1군 자리 200개
  시즌당 신규 진입   22.8명   (연 이직률 11.4%)
  시즌당 이탈        17.1명
  → 기대 재직기간    11.7시즌         (실제 MLB 이직률은 연 30~35%)

1군 타자 OVR:  최저 41 / 하위25% 46 / 중앙 49
팜 최상위 OVR: 50 48 48 48 47 47 46 46
```
부상자는 회복하면 자기 자리를 되찾는다. 자리를 영구히 빼앗기려면 **팜에 더 나은
선수가 대기하고 있어야 하는데, 팜 최상위가 1군 중앙값과 거의 같다.**
즉 병목은 부상이 아니라 **팜의 깊이와 하위권 재능 분포의 압축**이다.

측정 과정에서 통계 버그도 하나 찾았다. 25세에 팜에서 방출되는 선수는
`retired_year`가 설정되지 않아 커리어 통계에서 통째로 빠져 있었다.
1군을 잠깐 밟았다 사라진 선수들이 전부 누락된 채로 평균을 내고 있었다.
수정 후 은퇴 선수 954명 → 1202명, 평균 커리어 11.1 → **9.2시즌**,
통산 WAR 5 이상 비율 56% → 45%.

## 알려진 한계
- 커리어 길이 평균 9.2시즌은 여전히 실제(5~6년)보다 길다. 위 진단대로
  팜 깊이 / 재능 분포 / 팀 간 선수 이동(FA·트레이드·웨이버)이 필요하다.
- 경기 **중** 부상이 없다. 경기 종료 후 일괄 판정한다. 경기 도중 교체되는
  연출은 없지만 통계적으로는 동등하다.
- 부상 종류(햄스트링/팔꿈치/어깨)가 구분되지 않는다. 일수와 손상 배율만 있다.
- 재활 등판 / 복귀 후 컨디션 난조가 없다. 복귀 즉시 100%다.
- 백업 타석 비중이 12%로 실제(~25%)보다 낮다. 휴식일·플래툰·대타가 없기 때문이다.
