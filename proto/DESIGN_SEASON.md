# 시즌 루프 v0.1

## 구성 추가분
```
season.py           일정 생성 / 시즌 진행 / 기록 집계 / WAR / 포스트시즌
run_season.py       한 시즌 실행 + 리포트
validate_seasons.py 다중 시즌 분포 검증
```

## 일정 생성
circle method 라운드로빈. 8팀 84경기 = 7팀 상대 × 12회.
검증: 총 336경기 / 84경기일 / 팀당 84경기 / 홈 42·원정 42 / 상대별 정확히 12경기.

`games_per_team`이 `n_teams - 1`로 나누어떨어져야 한다 (8팀이면 84, 126, 140 등).
리그 규모를 바꿀 때 이 제약을 UI에서 막아야 한다.

## 불펜 휴식 관리 (시즌 레벨)
경기 엔진은 하루만 안다. 등판 간격은 시즌이 관리한다.
```
등판 후 휴식일 = 0 (상대타자 ≤4) | 1 (≤8) | 2 (초과)
3연투 이후 +1일, 4연투 이후 +2일 강제
등판 가능 투수가 3명 미만이면 강제로 채운다 (불펜 고갈 방지)
```
`Team.unavailable` 집합을 매 경기일 갱신하면 `TeamGameState`가 이를 읽어 제외한다.
→ 최다 등판 37경기 / 평균 31경기 (84경기 시즌). 144경기 환산 시 약 63경기로 현실적.

## 승·패·세이브 판정
초기 구현은 "선발이 5이닝 넘으면 선발이 승"이라는 조잡한 근사였고,
그 결과 불펜투수가 18승을 하는 사태가 났다. 실제 규칙에 맞춰 다시 구현했다.
```
매 타석 후 리드 변동을 감시한다.
공격팀이 리드를 잡는 순간:
    공격팀.por  = 그 시점 자기 팀 투수   (승리투수 후보)
    수비팀.lp   = 그 시점 자기 팀 투수   (패전투수 후보)
경기 종료 시 승리팀.por 에게 승, 패배팀.lp 에게 패.
단 por 가 선발이고 5이닝 미만이면 가장 많이 던진 구원투수에게 넘긴다.
세이브: 마지막 투수가 승리투수가 아니고 3점차 이내로 지킨 경우.
```

## 실점 귀속 (가장 중요한 수정)
초기 구현은 실점을 **점수가 난 시점의 투수**에게 기록했다. 그 결과 선발이
주자를 남기고 내려가면 그 실점이 전부 불펜 몫이 되어, 선발 ERA 2점대 / 리그 RA9 4.12
라는 불가능한 그림이 나왔다.

`Bases`가 주자마다 **책임투수(PitLine)** 를 함께 들고 다니도록 고쳤다.
```
bases.r[i]     주자
bases.resp[i]  그 주자를 출루시킨 투수
```
`put / take / move` 세 메서드로만 베이스를 조작해 둘이 절대 어긋나지 않게 했다.
→ 수정 후: 선발 ERA 4.17 (전체 이닝의 60%), 불펜 ERA 4.05.

## 게임 내부 WAR
실제 fWAR/bWAR를 복제하지 않는다. **정확성보다 일관성**이 중요하다.
```
타자  wOBA = (.69BB + .72HBP + .89·1B + 1.27·2B + 1.62·3B + 2.10HR) / PA
      wRAA = (wOBA - 리그wOBA) / 1.25 × PA
      포지션 보정 (600타석당): C +12.5 SS +7 2B/3B/CF +2.5 LF/RF -7 1B -12.5 DH -17.5
      대체수준 +20 / 600타석
      WAR = (wRAA + 포지션 + 대체수준) / 9.5

투수  대체수준 RA9 = 리그RA9 × 1.22 (선발) / 1.35 (구원)
      WAR = (대체수준RA9 - 본인ERA) × IP/9 / 9.5
```
FIP는 리그 상수를 더해야 한다 (원시값만 쓰면 음수가 나온다).
`fip_const = 리그ERA - 리그원시FIP`, 이번 시즌 기준 2.78.

## v0.1의 알려진 한계
- **규정타석 충족이 항상 72명(=8팀×9명 전원)이다.** 대타·대주자·휴식·부상이 없어
  주전 9명이 84경기를 전부 뛴다. 백업 선수는 로스터에만 존재하고 한 타석도 못 든다.
  → 부상 시스템과 라인업 관리가 들어가야 해결된다.
- 다승 1위가 10승으로 약간 낮다 (선발 평균 5.3이닝의 결과).
- 짧은 시즌(84경기)이라 타이틀 기록의 분산이 실제보다 크다. 정규 시즌 경기 수를
  늘리면 자연히 좁아진다.
- 경기일에 휴식일이 없다 (84일 연속). 선발 로테이션은 5인 순환이라 문제없지만
  실제 일정에 월요일 휴식 등을 넣으려면 스케줄러를 확장해야 한다.
- 무승부 없음 (연장 15회까지, 그 이후 무승부는 순위에 미반영).
