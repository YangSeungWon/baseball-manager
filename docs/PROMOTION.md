## 짧은 영상 구성

실제 플레이를 녹화합니다. 결과는 실제 해당 플레이의 결과를 사용합니다.

- 0–3초: “9회 말, 두 점 차”와 점수판.
- 3–7초: 투구 → 2.5초 카운트다운. “너라면 칠까, 참을까?”
- 7–12초: 선택 → 실제 타격/미트와 판정.
- 12–16초: 결과 카드 → “같은 상황에 도전”과 주소.

끝내기뿐 아니라 헛스윙, 볼을 참은 장면, 마지막 스트라이크도 소재가 됩니다.
선택 화면이나 단장 기능을 길게 설명하기보다 판단 순간을 먼저 보여줍니다.

## 공유 흐름

결과 → 결과와 링크 공유 → 친구가 링크 방문 → 같은 상황 시작 → 다른 선택 → 결과 공유.

- 공유 문구: 성공/실패, 투구 수, 득점, 안타와 도전 링크.
- 결과 카드: 기기에서 생성하는 1080×1080 PNG.
- 공유 링크: `?challenge=b2-<seed>`. 초기 상황만 전달하며 상대의 정답이나 결과는 노출하지 않음.
- 같은 시드와 선택은 같은 결과를 재현함. 다른 선택은 볼카운트와 이후 투구에 영향을 줄 수 있음.
- 온라인 순위나 검증된 기록으로 소개하지 않음. 현재 서버 순위 기능은 없음.
