## 커뮤니티 게시 초안

제목: 브라우저에서 하는 야구단 운영 게임을 만들었습니다 — Project Dugout

드래프트에서 뽑은 선수가 몇 년 뒤 주축이 되고, 8회 위기에서 투수를 바꿀지 고민하는 게임을 만들었습니다.

스카우트의 평가와 실제 경기 기록을 함께 보며 선수단을 운영합니다. FA 협상, 트레이드, 육성, 병역과 외국인 선수 운영도 들어 있습니다.
경기를 직접 지켜보거나 감독에게 맡겨 여러 날을 진행할 수 있습니다. 큰 부상 등 중요한 소식이 생기면 자동 진행이 멈춥니다.

무료이고 설치나 가입이 필요 없습니다. 세이브는 브라우저에 저장되며 파일로 내보낼 수 있습니다.
구단과 선수는 모두 가상입니다.

https://baseball.ysw.kr

처음 시작했을 때 어디서 막히는지, 어떤 결정이 재미있었는지 알려 주시면 개선에 도움이 됩니다.

게시 전 각 커뮤니티의 제작자 홍보 규칙을 확인한다. 동일 글을 여러 곳에 한꺼번에 배포하지 않는다.

## 영상 세 편의 구성

실제 플레이를 녹화하며 가상의 수치를 실제 결과처럼 제시하지 않는다.

1. **누구를 지명할까?** (15–20초): 지명 후보 둘의 현재 평가·잠재력·확신도를 비교 → 리포트 → 지명. 마지막에 플레이 주소.
2. **내가 뽑은 선수가 여기까지** (20–30초): 실제 지명 당시 리포트 → 시즌 기록 → 선수 카드. 충분한 커리어를 진행한 저장본으로 촬영한다.
3. **8회, 바꿀까 맡길까?** (15–25초): 점수·주자·투구수 → 투수 교체 선택 → 실제 결과. 성공과 실패 모두 소재가 된다.

## 준비된 파일

- `web/media/dugout-preview.png`: 1200×630 링크 미리보기. 화면의 눈금 표현을 활용한 소개 이미지이며 실제 선수 기록은 아니다.
- `tools/preview.html`, `tools/render-preview.mjs`: 미리보기 이미지 원본과 생성 도구.
- `tools/package-itch.py`: `web/`를 itch.io용 ZIP으로 패키징. 기본 출력 `/tmp/dugout-itch.zip`.
- 실제 게임의 선수 상세에서 카드 이미지와 소개 글을 내보낼 수 있다.
- 우승 화면에서는 우승 소개 글을 복사할 수 있다.

## 첫 플레이테스트

광고비를 쓰기 전에 자발적 참가자 5–10명과 진행한다. 먼저 설명하지 않고 관찰한다.

- 구단을 고르고 첫 경기를 시작할 수 있는가?
- 현재 평가와 잠재력 막대의 차이를 자기 말로 설명하는가?
- 후보 둘을 비교하고 원하는 선수를 지명할 수 있는가?
- 자동 진행이 멈춘 이유와 다음 행동을 찾는가?
- 브라우저를 닫았다가 이어서 진행할 수 있는가?
- 한 시즌 뒤 다른 시즌을 하고 싶은가? 가장 기억나는 선수와 결정은 무엇인가?

소요 시간, 막힌 지점, 도움 요청 횟수, 다시 플레이하고 싶은 이유를 관찰 기록으로 남긴다. 게임에 추적 도구는 넣지 않는다. 이후 채널별 유입 반응은 해당 게시 플랫폼이 제공하는 집계와 자발적 피드백으로 비교한다.
